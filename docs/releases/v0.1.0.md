# v0.1.0

## Highlights

- First public source release of Prompt Benchmark.
- Includes the teaching activity web app, NestJS API, Supabase migrations, and synthetic seed data.
- Removes private workflow folders, local deployment metadata, screenshots, historical reports, and real learner roster data.
- Adds a backend data-source boundary so maintainers can keep Supabase or build a custom API adapter.

## Installation

```bash
npm install
cp apps/api/.env.example apps/api/.env
cp apps/web/.env.example apps/web/.env.local
npm run dev
```

## Verification

- `npm audit --omit=dev`
- `npm run lint`
- `npm run build`

## Notes

This release does not include real classroom data, historical Git commits, private screenshots, or production credentials.
