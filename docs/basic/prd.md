# 产品逻辑说明

## 问题与目标

Prompt Benchmark 支撑提示词活动、活动列表、参与者提交、AI 配置、评估和看板统计。本文建立现有产品逻辑基线，让维护者先理解真实范围，再进入新需求或实现改动。

## 用户故事

- 作为普通用户，我希望用清晰入口完成核心任务，并在处理中、成功、失败时知道下一步。
- 作为维护者，我希望快速定位页面、服务、配置和文档边界。
- 作为贡献者，我希望在修改前获得可靠的产品范围和验收线索。

## 功能范围

- 记录当前已经存在的核心流程、源码结构、服务边界和技术栈。
- 记录活动作为数据聚合根的边界，历史活动和新活动的数据需要按活动隔离。
- 支撑公开维护者理解教学活动、数据源和 AI 评分边界。
- 不在本文新增未确认功能、付费规则或接口契约。

## 验收标准

- 后续维护者能从本文理解当前产品边界。
- 后续功能改动能从本文判断是否影响产品逻辑。
- 文档内容不包含模板占位语句。

## 维护规则

- 产品定位、核心流程、范围或验收方式变化后更新本文。
- 新需求进入实现前，先明确用户场景、数据影响和验证方式。
