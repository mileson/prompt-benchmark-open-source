# 项目文件结构

## 项目定位

Prompt Benchmark 是Web + API 工作区。面向提示词活动运营、参与者提交和评估管理的基准测试平台，覆盖活动列表、活动配置、提交收集、AI 配置和看板统计。

## 核心目录

- `apps/web`: 前端应用入口和页面。
- `apps/api`: API 服务、模块和公共基础设施。
- `apps/api/src/modules`: API 服务、模块和公共基础设施。
- `apps/api/src/common`: API 服务、模块和公共基础设施。
- `supabase`: 默认数据库迁移和合成 seed。
- `docs`: 公开配置、数据源和隐私说明。

## 文件组织规则

- 业务源码、资源、测试、脚本和公开文档按职责分区维护。
- 新增源码文件时，同步检查文件头说明书和所在文件夹 README。
- 第三方依赖、构建产物和生成缓存不进入人工源码说明书范围。

## 维护规则

- 新增、删除或移动核心目录后，同步更新本文。
- 本文只记录已经存在的结构和流程事实。
