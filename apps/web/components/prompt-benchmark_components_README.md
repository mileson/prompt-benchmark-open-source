# components 文件夹说明书

## 核心功能

维护 Prompt Benchmark 中 apps/web/components 目录的源码、配置或资源边界，包括活动列表、现场大屏、提交页和管理配置相关组件。

## 输入

来自上游页面、服务、构建流程、用户动作或相邻模块的数据与调用。活动列表组件接收活动数据、管理密码输入、新建活动动作、活动名称修改动作和同学参加方式设置。

## 输出

向项目其他模块提供视图、服务、类型、配置、脚本或资源。活动入口组件负责展示活动总览、新建活动弹窗、活动设置弹窗、同学参加方式，以及进入大屏、提交页、管理页的操作。

## 定位

该目录是 Web + API 工作区 的局部职责单元，不承载跨目录的无关实现。

## 依赖

依赖项目运行框架、相邻模块、公共工具和必要的第三方库。

## 维护规则

- 新增、删除、移动文件或调整目录职责后，同步更新本 README。
- 目录职责影响产品流程、技术栈或服务边界时，同步更新 docs/basic。
