# activities 文件夹说明书

## 核心功能

维护 Prompt Benchmark 中 apps/api/src/modules/activities 目录的源码、配置或资源边界，包括活动查询、活动列表、活动创建和活动设置。

## 输入

来自上游页面、服务、构建流程、用户动作或相邻模块的数据与调用。活动创建入口接收活动名称、同学参加方式和管理密码，活动设置入口可接收新的活动名称与同学参加方式；活动访问入口可接收数字编号或历史 slug。

## 输出

向项目其他模块提供视图、服务、类型、配置、脚本或资源。活动列表会返回活动基础信息、同学参加方式、按创建顺序生成的数字访问路径和按活动隔离的参与、提交、评分统计，活动设置会保存用户可见的活动名称和参加方式。

## 定位

该目录是 Web + API 工作区 的局部职责单元，不承载跨目录的无关实现。

## 依赖

依赖项目运行框架、相邻模块、公共工具和必要的第三方库。

## 维护规则

- 新增、删除、移动文件或调整目录职责后，同步更新本 README。
- 目录职责影响产品流程、技术栈或服务边界时，同步更新 docs/basic。
