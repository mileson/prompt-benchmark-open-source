# dto 文件夹说明书

## 核心功能

维护 Prompt Benchmark 中 apps/api/src/modules/activities/dto 目录的源码、配置或资源边界，包括活动创建和活动设置请求结构。

## 输入

来自上游页面、服务、构建流程、用户动作或相邻模块的数据与调用。创建活动时接收活动名称和同学参加方式，活动设置时接收活动名称、同学参加方式、开关、轮询间隔和主题。

## 输出

向项目其他模块提供视图、服务、类型、配置、脚本或资源。

## 定位

该目录是 Web + API 工作区 的局部职责单元，不承载跨目录的无关实现。

## 依赖

依赖项目运行框架、相邻模块、公共工具和必要的第三方库。

## 维护规则

- 新增、删除、移动文件或调整目录职责后，同步更新本 README。
- 目录职责影响产品流程、技术栈或服务边界时，同步更新 docs/basic。
